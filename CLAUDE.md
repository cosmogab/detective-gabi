# Claude Code specifics

- Read `SPEC.md`, `PLAN.md` and `TASKS.md` before the first task. They are the source of truth.
- Work through `TASKS.md` in order. Announce the task id, do it, run the tests, commit, stop.
- Use the repo's existing patterns before introducing a new one.
- When you finish a task, report in three lines: what changed, what the test proves, the commit
  message you used.
